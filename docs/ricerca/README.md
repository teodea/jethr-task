# Ricerca

Output della skill `/research`: un file per domanda, ogni affermazione tracciata
alla fonte primaria che la possiede (Agenzia delle Entrate, INPS, Gazzetta
Ufficiale, delibere di comune e regione per le addizionali).

Mai un riassunto di terze parti: se una fonte cita una norma, si risale alla norma.

Convenzione di naming: `<argomento-in-kebab-case>.md`, con l'anno di riferimento
dentro al file, non nel nome — le aliquote cambiano e il file va aggiornato, non
duplicato.
